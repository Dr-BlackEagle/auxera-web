# Auxera Web

Seslendirmenler için kayıt ve düzenleme stüdyosu — web sürümü (iPhone, iPad ve masaüstü tarayıcılar).

- Uygulama: https://dr-blackeagle.github.io/auxera-web/
- Mikrofon deneme sayfası: https://dr-blackeagle.github.io/auxera-web/deneme.html

iPhone/iPad'de Safari → Paylaş → **Ana Ekrana Ekle** ile ekleyip oradan açın; böylece kayıtlar kalıcı olur.
Kayıtlar yalnızca bu cihazdaki tarayıcı deposunda tutulur, bir sunucuya gönderilmez.
